# stack-implementation-in-c
Implementation of Stack Data Structure in C using an array. Includes Push, Pop, Peek, isEmpty, isFull, and Display operations with Stack Overflow and Stack Underflow handling.
# Stack Implementation in C Using Array

## About
This project implements a Stack Data Structure in C using an array with a maximum size of 5.

## Operations
- **Push:** Insert an element into the stack.
- **Pop:** Remove the top element.
- **Peek:** View the top element.
- **isEmpty:** Check whether the stack is empty.
- **isFull:** Check whether the stack is full.
- **Display:** Display all stack elements.
- **Exit:** Terminate the program.

## Concepts Used
- C Programming
- Arrays
- Functions
- Switch Case
- Loops
- Stack Data Structure (LIFO)

## How to Run
1. Save the code as `stack.c`.
2. Compile the program:
   ```bash
   gcc stack.c -o stack
   ```
3. Run the program:
   ```bash
   ./stack
   ```

On Windows, run `stack.exe` after compilation.
